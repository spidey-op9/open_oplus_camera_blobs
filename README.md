# open_oplus_camera_blobs

Extracted and patched blobs for [open_oplus_camera](https://github.com/Tonybytelabs/open_oplus_camera).
Everything here is generated by its `extract-files.py`; do not edit by hand. Regenerate it there and
commit the output here.

Clone to `vendor/oplus/camera-blobs`. Files over 95 MB are stored as 20 MiB `.partNN` pieces that
open_oplus_camera's `vendorsetup.sh` joins.
